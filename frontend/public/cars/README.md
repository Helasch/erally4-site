# Photos des voitures (bandeau des profils pilotes)

Une image détourée (fond transparent, WebP) par voiture, nommée d'après le modèle :

| Voiture | Fichier |
|---|---|
| Peugeot 208 Rally4 | `peugeot-208-rally4.webp` |
| Renault Clio Rally4 | `renault-clio-rally4.webp` |
| Opel Corsa Rally4 | `opel-corsa-rally4.webp` |
| Ford Fiesta MK8 Rally4 | `ford-fiesta-mk8-rally4.webp` |

Utiliser uniquement des images dont on a les droits (captures du jeu EA SPORTS WRC).
Si un fichier manque, le profil s'affiche simplement sans voiture.
